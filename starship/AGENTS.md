# `starship/` — Starship Prompt Configuration

Files in this directory configure the Starship cross-shell prompt and are installed into `~/.config/` on Omarchy 4.5+.

## `starship.toml`

- Copied to `~/.config/starship.toml` with permissions `0644`.
- Uses a multi-line prompt format featuring user, host (with `[SSH]` indicator), full directory path, git branch and status symbols, and prompt character.
- Styled in bold red and cyan accents to harmonize with the Omarchy terminal color scheme.
